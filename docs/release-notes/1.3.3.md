## Kannu 1.3.3 — Heimdall

Kannu now asks you to accept its Terms of Use before it starts, and ADR Detection reads long chats
more carefully while sending less of them.

Requires macOS 14.6 or later (unchanged since 1.2.0). Existing installs update in place.

---

### You'll be asked to accept the Terms of Use

The first time you open 1.3.3, Kannu shows its Terms of Use, and until you accept them it does
nothing at all: no notch, no agent hooks, no permission prompts, no background helpers. This applies
to existing installs too. Nobody had agreed to anything before, so everyone accepts once. Tick the
box and choose **Accept** to carry on as before; **Decline** quits.

In plain terms: Kannu is free software provided as is, without warranty. Its security features are
best-effort, so they can miss things, and a quiet notch is not proof that nothing happened. The full
text is in **Settings › About › Legal**, which also shows when you accepted it. The GPL licence now
ships inside the app too, where it always should have been.

If the terms ever change in a way that matters, Kannu shows them again on launch.

### ADR Detection: less sent, more seen

These changes only matter if you have turned on **Analyze chats with ADR Detection**, which is
opt-in and runs one chat at a time when you ask.

- **An injection at the end of a long tool result now survives.** Long tool output used to be trimmed
  from the front, so an instruction planted at the *end* of a fetched page could be cut before the
  detector ever saw it. Output is now trimmed so that both its start and its end are kept.
- **Around 40% less input per analysis**, measured on real transcripts, so each run costs less.
- **Tool output is labelled as untrusted.** Every tool result the detector reads is fenced and marked
  as data, not instructions, and the commands your agent ran are kept rather than dropped.
- **New analyses default to `claude-sonnet-5`.**

Everything else, including the 1.3.2 battery fix, is unchanged.
