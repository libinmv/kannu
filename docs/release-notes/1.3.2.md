## Kannu 1.3.2 — Heimdall

A small follow-up to 1.3.1: grouped security findings now tell you which chats they came from
without you having to expand them.

Requires macOS 14.6 or later (unchanged since 1.2.0). Existing installs update in place.

---

### Grouped findings name their chats

1.3.1 started showing one row per problem instead of one per sighting — so a rule that fired in
three different chats became a single row. That is the right grouping, but the row only said *how
many* occurrences, and you had to expand it to find out **where**. For most findings the chat is how
you recognise what actually happened.

A row now reads:

> **Policy matched "ssh" — it ran**
> 7 occurrences · 3 chats · first 17 Sep at 15:49 · last 25 Sep at 16:41
> Tenant Delete Agent, gitlab orchestration, +1

Expanding it still lists every chat in full, along with the projects and how many separate sightings
were folded together. A finding that only ever appeared in one chat shows no chat line — there is
nothing to disambiguate.

Nothing about grouping or acknowledgement changed: acknowledging still settles the problem rather
than the sighting, still stays quiet while it recurs, and still comes back only if it gets worse.
